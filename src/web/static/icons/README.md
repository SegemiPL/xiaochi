# 界面图标来源

- 小弛品牌复用 `../favicon.svg`，与浏览器标签页保持一致。
- `tax-header.png`：国家税务总局官网页头原始图片，下载于 2026-10-08。来源：https://www.chinatax.gov.cn/chinatax/xhtml/New_chinatax/static/2023/images/public/header_logo.png 。文件未修改，CSS 仅展示左侧完整国徽区域，用于对应官方外链的识别。
- `mof-header.png`：财政部官网页头原始图片，下载于 2026-10-08。来源：https://www.mof.gov.cn/images/czb_logo_zwnew.png 。文件未修改，CSS 仅展示左侧完整国徽区域，用于财政部外链。
- `policy-library.svg`：项目自绘的书册功能图标，用于政策法规库入口，并非机构官方标识。

图标随前端本地提供，页面加载不依赖第三方图片请求。链接旁保留完整机构或资料库名称；装饰图标不重复朗读。
