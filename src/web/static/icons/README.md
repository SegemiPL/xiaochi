# 界面图标来源

- 小弛侧栏品牌使用 `../mascot/xiaochi-sprite.png`：基于用户提供的人物参考图，通过内置 imagegen 生成的透明 Q 版精灵图；动画、来源与生成提示见 `../mascot/README.md`。浏览器标签页保留 `../favicon.svg`。
- `tax-header.png`：国家税务总局官网页头原始图片，下载于 2026-10-08。来源：https://www.chinatax.gov.cn/chinatax/xhtml/New_chinatax/static/2023/images/public/header_logo.png 。文件未修改，CSS 仅展示左侧完整国徽区域，用于对应官方外链的识别。
- `mof-header.png`：财政部官网页头原始图片，下载于 2026-10-08。来源：https://www.mof.gov.cn/images/czb_logo_zwnew.png 。文件未修改，CSS 仅展示左侧完整国徽区域，用于财政部外链。
- `policy-library.svg`：项目自绘的书册功能图标，用于政策法规库入口，并非机构官方标识。

图标随前端本地提供，页面加载不依赖第三方图片请求。链接旁保留完整机构或资料库名称；装饰图标不重复朗读。

- `safe.ico`：国家外汇管理局官网声明的 favicon，下载于2026-10-12。来源：https://www.safe.gov.cn/safe/templateresource/372b1dfdab204181b9b4f943a8e926a6/images/safe.ico 。原文件未修改，用于外汇局外链。
- `ndrc-header.png`：国家发展改革委官网页头原始图片，下载于2026-10-12。来源：https://www.ndrc.gov.cn/images/logonew.png ，由官网 `jslm/headtop/headtop.js` 引用。原文件未修改，CSS 展示左侧完整国徽，用于发改委外链。
